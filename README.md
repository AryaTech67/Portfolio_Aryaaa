# Portfolio Pribadi — Arya Putra Pratama

Portofolio resmi **Arya Putra Pratama**, siswa Kelas 11 Rekayasa Perangkat Lunak (RPL) di **SMK Darus Sa'adah Bogor**. Dibangun menggunakan **Next.js (App Router)**, **React**, **TypeScript**, dan **Tailwind CSS**, dioptimalkan untuk performa tinggi dan siap di-deploy langsung ke **Vercel**.

---

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Library Antarmuka:** React 18 / 19
- **Bahasa:** TypeScript
- **Styling:** Tailwind CSS (Dark Mode Slate-950, Emerald Glow)
- **Ikon:** Lucide React & Vector SVG
- **Font:** Inter & JetBrains Mono

---

## 🚀 Panduan Menjalankan Proyek Lokal

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Jalankan Development Server:**
   ```bash
   npm run dev
   ```

3. **Buka di Browser:**
   Akses `http://localhost:3000`

4. **Build untuk Produksi:**
   ```bash
   npm run build
   npm run start
   ```

---

## 🌐 Panduan Deploy ke Vercel

1. Buat repository baru di GitHub kamu (`AryaTech67`).
2. Hubungkan folder proyek dan lakukan push:
   ```bash
   git init
   git add .
   git commit -m "feat: portfolio next.js app router"
   git branch -M main
   git remote add origin https://github.com/AryaTech67/portfolio.git
   git push -u origin main
   ```
3. Buka [Vercel Dashboard](https://vercel.com/new).
4. Klik **Import Project** dari repository GitHub kamu.
5. Biarkan preset build default (Next.js) dan klik **Deploy**.
6. Website kamu langsung aktif online dengan domain `.vercel.app`!
